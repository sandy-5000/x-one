Sorting Tricks

What it is

Sorting transforms the problem — enabling two pointers, greedy, or binary search. Often sort by one key, tie-break by another.

When to use

  • Pairs/events need processing in order.
  • "Minimum maximum" after reordering.
  • Coordinate compression precursor.

Custom comparators (C++)

sort(v.begin(), v.end(), [](const auto& a, const auto& b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;  // tie-break
});

Examples

1. Sort pairs by second, greedy on first

Interval scheduling — sort by end time.

2. CF 702C — Cellular Network

Sort cities and towers, two pointers for nearest tower.

3. Sort by angle / polar order

Geometry problems — sort points around pivot.

4. Sort + unique (dedup)

sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());

5. CF 1690C — Restoring the Duration of Tasks

Sort events, simulate with priority queue.

6. Order statistic after sort

k-th smallest = a[k] after sort (or nth_element for partial).

Useful STL

  • sort — O(n log n)
  • stable_sort — keeps equal order
  • nth_element — O(n) average for k-th element
  • lower_bound / upper_bound — on sorted range

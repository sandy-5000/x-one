Binary Search on Answer

What it is

The answer is a number (time, distance, minimum max, maximum min). You binary search that value and write a check(mid) function that returns true/false with monotonic behavior.

When to use

  • "Minimum possible maximum …" or "Maximum possible minimum …"
  • "Can we finish within T time?"
  • Answer is integer in a large range [lo, hi].

Pattern

bool ok(long long mid) {
    // simulate / greedy / count — can we achieve mid?
}

long long lo = MIN_ANS, hi = MAX_ANS, ans = MAX_ANS;
while (lo <= hi) {
    long long mid = lo + (hi - lo) / 2;
    if (ok(mid)) { ans = mid; hi = mid - 1; }  // minimize
    else lo = mid + 1;
}
// For maximize: if (ok(mid)) { ans = mid; lo = mid + 1; } else hi = mid - 1;

Examples

1. Minimum maximum segment sum

Problem: Split array into k parts, minimize the largest part sum. Binary search the largest part sum X, greedily form segments each with sum ≤ X.

2. Aggressive cows (classic)

Problem: Place k cows in stalls, maximize minimum distance. Binary search distance d, greedily place cows.

CF analogue: CF 883I — Groups of Students (similar spirit)

3. CF 1701C — Schedule

Binary search minimum time to complete all jobs with k workers.

4. CF 1843D — Ranking Permutation

Binary search answer on permutation construction.

5. Minimum days to make m bouquets

Binary search days; check if enough flowers bloomed.

Check function tips

  • Usually greedy or simulation.
  • Use long long — mid values overflow int.
  • If ok(mid) is true for all larger mids, you're minimizing; reverse for maximizing.

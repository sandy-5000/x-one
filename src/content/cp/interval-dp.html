Interval DP

What it is

dp[l][r] = optimal answer for subarray/substring [l, r]. Merge smaller intervals into larger — O(n³) or O(n²) with optimization.

When to use

  • Matrix chain multiplication.
  • Burst balloons, merge stones.
  • Palindrome partitioning, clear the string.

Template

for (int len = 2; len <= n; len++)
    for (int l = 0; l + len - 1 < n; l++) {
        int r = l + len - 1;
        dp[l][r] = INF;
        for (int k = l; k < r; k++)
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost(l, k, r));
    }

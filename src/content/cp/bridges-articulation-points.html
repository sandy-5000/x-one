Bridges & Articulation Points

What it is

  • Bridge: edge whose removal disconnects graph.
  • Articulation point: vertex whose removal increases connected components.

Found by DFS with low-link values in O(V + E).

When to use

  • Network reliability, 2-edge-connected components.
  • Tree + one extra edge problems.
  • Block-cut tree construction (advanced).

Template (bridges)

vector<int> tin, low;
int timer = 0;
vector<pair<int,int>> bridges;

void dfs(int u, int p, vector<vector<int>>& adj) {
    tin[u] = low[u] = timer++;
    for (int v : adj[u]) {
        if (v == p) continue;
        if (tin[v] == -1) {
            dfs(v, u, adj);
            low[u] = min(low[u], low[v]);
            if (low[v] > tin[u]) bridges.push_back({u, v});
        } else {
            low[u] = min(low[u], tin[v]);
        }
    }
}

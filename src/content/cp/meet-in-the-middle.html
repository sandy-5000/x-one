Meet in the Middle

What it is

Split input in half, enumerate all possibilities for each half, combine. Turns O(2^n) into O(2^(n/2)) — works for n ≤ 40.

When to use

  • Subset sum closest to target.
  • Count pairs with given sum from two halves.
  • Hamiltonian path on ~40 nodes (with pruning).

Template (subset sum)

int n = a.size();
int m1 = n/2, m2 = n - m1;
vector<long long> left, right;

for (int mask = 0; mask < (1<<m1); mask++) {
    long long s = 0;
    for (int i = 0; i < m1; i++) if (mask>>i&1) s += a[i];
    left.push_back(s);
}
// same for right half
sort(left.begin(), left.end());

long long ans = LLONG_MAX;
for (long long s : right) {
    long long need = target - s;
    auto it = lower_bound(left.begin(), left.end(), need);
    if (it != left.end()) ans = min(ans, abs(*it + s - target));
    if (it != left.begin()) ans = min(ans, abs(*prev(it) + s - target));
}

Examples

1. CF 888E — Maximum Subsequence

Meet in the middle for subset sum mod m.

2. 4-sum problem

Pair sums from two halves, two-pointer on sorted lists.

3. CF 1006F — Xor-Subsequence

Split and combine XOR sums.

4. Count subsets with sum = K (n ≤ 40)

Enumerate both halves, hash left sums.

5. Traveling salesman (n ≤ 20 uses bitmask; n ≤ 40 might use MITM on paths)

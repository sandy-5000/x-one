Dijkstra's Algorithm

What it is

Shortest path from source in non-negative weighted graph in O((V+E) log V) with priority queue.

When to use

  • Weighted shortest path (edges ≥ 0).
  • Multi-source: add super-source with 0-weight edges.
  • 0-1 BFS when weights are only 0 and 1 (faster alternative).

Template

vector<long long> dist(n, LLONG_MAX);
priority_queue<pair<long long,int>, vector<...>, greater<...>> pq;
dist[s] = 0; pq.push({0, s});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d != dist[u]) continue;
    for (auto [v, w] : adj[u])
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
}

0-1 BFS

deque<int> dq;
dist[s] = 0; dq.push_front(s);
while (!dq.empty()) {
    int u = dq.front(); dq.pop_front();
    for (auto [v, w] : adj[u])
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            w ? dq.push_back(v) : dq.push_front(v);
        }
}

Pitfalls

  • Negative edges → Bellman-Ford (rare at 1950).
  • Stale entries in PQ — always check d == dist[u].

Longest Increasing Subsequence (LIS)

What it is

Longest strictly increasing subsequence in O(n log n) using patience sorting / binary search on tails array.

When to use

  • LIS length or count (with modifications).
  • Longest non-decreasing subsequence.
  • Patience sorting pattern: tails[len] = smallest ending value of IS of length len+1.

O(n log n) template

vector<int> tails;
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x;
}
int lis_len = tails.size();

For non-decreasing, use upper_bound instead of lower_bound.

Examples

1. CF 977F — Consecutive Subsequence

LIS variant with consecutive values — hash map DP.

2. CF 1365B — Trouble Sort

Greedy + LIS insight on differences.

3. Russian doll envelopes

Sort by width asc, height desc; LIS on heights.

4. Maximum number of non-overlapping intervals

Sort + greedy (related but not LIS).

5. LIS reconstruction

Store parent pointers when updating tails (more code, rarely needed in CF).

O(n²) DP (only if n ≤ 5000)

dp[i] = 1;
for (int j = 0; j < i; j++)
    if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);

Functional Graphs

What it is

Each node has exactly one outgoing edge (next[i]). Structure: cycles with trees feeding into them (rho-shaped).

When to use

  • f(x) iterated — find cycle, period, steps to cycle.
  • CF "badge" / permutation successor problems.
  • Binary lifting on functional graph for k-th jump.

Template (cycle detection)

vector<int> state(n);  // 0 unvisited, 1 in path, 2 done
vector<int> cycle_nodes;

void dfs(int u) {
    state[u] = 1;
  int v = nxt[u];
    if (state[v] == 0) dfs(v);
    else if (state[v] == 1) {
        // extract cycle from v to u
        for (int x = v; ; x = nxt[x]) {
            cycle_nodes.push_back(x);
            if (x == u) break;
        }
    }
    state[u] = 2;
}

Binary lifting on functional graph

// jump[u][k] = 2^k-th successor of u
for (int k = 1; k < LOG; k++)
    jump[u][k] = jump[jump[u][k-1]][k-1];

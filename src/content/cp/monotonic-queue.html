Monotonic Deque (Queue)

What it is

Deque maintaining monotonic order for sliding window minimum/maximum in O(n).

When to use

  • Fixed window size k: min/max in each window.
  • CF problems with "best in last k elements."

Sliding window maximum template

deque<int> dq;  // indices, values decreasing
vector<int> ans;
for (int i = 0; i < n; i++) {
    while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
    while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
    dq.push_back(i);
    if (i >= k - 1) ans.push_back(a[dq.front()]);
}

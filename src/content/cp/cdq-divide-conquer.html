CDQ Divide & Conquer (Offline)

What it is

Offline algorithm processing queries in divide-and-conquer order. Solves 2D partial order / inversion / 3D dominance problems in O(n log² n).

When to use

  • Dynamic inversion count offline.
  • 3D dominance: count points with x < X, y < Y, z < Z.
  • DP optimization when transitions are "points dominated in 2D."

Pattern

  1. Divide time/queries into left and right halves.
  2. Process contributions from left half affecting right half (sweep).
  3. Recurse on both halves.

Simpler offline: "sort + BIT"

Many "CDQ" problems at 1900 are solved by:

  • Sort queries by one dimension.
  • Sweep with Fenwick tree on second dimension.

Trie & XOR Trie

What it is

Trie: tree on bits/characters for prefix queries. XOR Trie: store numbers bit-by-bit; query max xor with given value in O(log MAX).

When to use

  • Maximum xor pair / max xor subarray.
  • Prefix xor problems.
  • Insert/query strings by prefix.

XOR Trie template

struct XorTrie {
    struct Node { int ch[2] = {-1,-1}; int cnt = 0; };
    vector<Node> t;
    int bits = 30;
    XorTrie() { t.push_back({}); }

    void insert(int x) {
        int u = 0; t[u].cnt++;
        for (int b = bits; b >= 0; b--) {
            int c = (x >> b) & 1;
            if (t[u].ch[c] == -1) {
                t[u].ch[c] = t.size();
                t.push_back({});
            }
            u = t[u].ch[c]; t[u].cnt++;
        }
    }

    int max_xor(int x) {
        int u = 0, res = 0;
        for (int b = bits; b >= 0; b--) {
            int c = (x >> b) & 1;
            int want = 1 - c;
            if (t[u].ch[want] != -1) { res |= (1<<b); u = t[u].ch[want]; }
            else u = t[u].ch[c];
        }
        return res;
    }
};

Examples

1. CF 888G — XOR Gate

Max xor pair — insert and query.

2. CF 1847C — Vampiric Powers

Prefix xor + trie.

3. CF 165E — Compatible Numbers

SOS DP or trie on bits.

4. Maximum xor subarray

Prefix xor array + trie.

5. String trie for autocomplete / prefix count.

Prefix Sums

What it is

pref[i] = a[0] + a[1] + ... + a[i-1] (or product, XOR, etc.). Range query in O(1) after O(n) preprocess.

When to use

  • Many range sum queries on static array.
  • Subarray sum equals K (combine with hash map).
  • 2D grid sum queries → 2D prefix sums.

Templates

1D

vector<long long> pref(n + 1);
for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + a[i];
// sum [l, r] inclusive (0-indexed)
long long s = pref[r + 1] - pref[l];

2D

pref[i+1][j+1] = a[i][j] + pref[i][j+1] + pref[i+1][j] - pref[i][j];
// rectangle (x1,y1) to (x2,y2) inclusive
long long s = pref[x2+1][y2+1] - pref[x1][y2+1] - pref[x2+1][y1] + pref[x1][y1];

Prefix XOR

Same formula works for XOR (inverse is XOR itself).

Examples

1. Subarray sum equals K

Count pairs where pref[r] - pref[l] = K → store pref frequencies in hash map.

2. CF 433B — Kuriyama Mirai's Stones

Prefix sums for range queries on two arrays.

3. CF 295A — Greg and Array

Difference array + prefix idea for range updates.

4. Grid path sum queries

2D prefix on cost matrix.

5. Equilibrium index

Find i where sum left = sum right using prefix.

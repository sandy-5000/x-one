Dynamic Programming — 1D

What it is

dp[i] = optimal answer for prefix/subproblem ending at i. Transition from smaller indices.

When to use

  • Count ways / min cost / max value on sequence.
  • Decision at each step depends on previous few states.
  • State space is O(n), transitions O(1) or O(small).

Template

vector<long long> dp(n);
dp[0] = base;
for (int i = 1; i < n; i++) {
    dp[i] = best over j < i of (dp[j] + cost(j, i));
}

Classic examples

1. Climbing stairs

dp[i] = dp[i-1] + dp[i-2] — count ways.

2. House robber

dp[i] = max(dp[i-1], dp[i-2] + a[i]).

3. CF 189A — Cut Ribbon

Unbounded knapsack on lengths — dp[x] = max(dp[x-l] + 1).

4. CF 455A — Boredom

Take or skip with constraint on adjacent values — compress values, DP on value domain.

5. Longest path in DAG (linearized)

Topo order → 1D DP on nodes.

Space optimization

If dp[i] only needs dp[i-1] and dp[i-2]:

long long prev2 = 0, prev1 = 0;
for (int i = 0; i < n; i++) {
    long long cur = max(prev1, prev2 + a[i]);
    prev2 = prev1; prev1 = cur;
}

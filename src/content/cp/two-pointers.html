Two Pointers

What it is

Maintain two indices l and r on a sequence, moving them based on a condition — typically O(n) after sorting.

When to use

  • Sorted array: find pairs with given sum/property.
  • Remove duplicates in-place.
  • Merge two sorted arrays/lists.
  • Partition array (Dutch national flag).

Templates

Opposite ends (sorted array, pair sum)

int l = 0, r = n - 1;
while (l < r) {
    int s = a[l] + a[r];
    if (s == target) { /* found */ break; }
    else if (s < target) l++;
    else r--;
}

Same direction (chase)

int j = 0;
for (int i = 0; i < n; i++) {
    while (j < n && condition(i, j)) j++;
    // window [i, j) or similar
}

Examples

1. Two sum in sorted array

Find if any pair sums to S. Opposite pointers — O(n).

2. CF 279B — Books

Max consecutive books with total height ≤ t. Sliding two pointers on array.

3. CF 1536C — Diluc and Kaeya

Two pointers on two strings for LCP-style matching.

4. Three sum (reduce to two sum)

Fix one element, two-pointer on the rest.

5. Remove duplicates from sorted array

int w = 0;
for (int r = 0; r < n; r++)
    if (r == 0 || a[r] != a[r-1])
        a[w++] = a[r];

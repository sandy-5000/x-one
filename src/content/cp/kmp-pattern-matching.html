KMP Pattern Matching

What it is

Find all occurrences of pattern P in text T in O(|T| + |P|) using failure function (prefix function).

When to use

  • Substring search, period detection.
  • String matching with borders.
  • Some DP on strings with pattern structure.

Prefix function template

vector<int> pi(string s) {
    int n = s.size();
    vector<int> p(n);
    for (int i = 1; i < n; i++) {
        int j = p[i-1];
        while (j > 0 && s[i] != s[j]) j = p[j-1];
        if (s[i] == s[j]) j++;
        p[i] = j;
    }
    return p;
}

// match pattern in text
int j = 0;
for (int i = 0; i < text.size(); i++) {
    while (j > 0 && text[i] != pat[j]) j = pi[j-1];
    if (text[i] == pat[j]) j++;
    if (j == pat.size()) { /* match at i - j + 1 */ j = pi[j-1]; }
}

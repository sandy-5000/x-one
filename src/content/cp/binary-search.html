Binary Search (on Sorted Data)

What it is

Find a value or boundary in O(log n) on a sorted array (or any structure where a monotonic predicate holds).

When to use

  • Array is sorted (or you can sort it).
  • You need: first ≥ x, last ≤ x, count of elements ≤ x, or check if value exists.
  • Predicate P(mid) is monotonic: false…false, true…true (or reverse).

Template (C++)

// first index i where a[i] >= x (or n if none)
int lo = 0, hi = n;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] >= x) hi = mid;
    else lo = mid + 1;
}
// lo is the answer

// last index i where a[i] <= x
int lo = 0, hi = n - 1, ans = -1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] <= x) { ans = mid; lo = mid + 1; }
    else hi = mid - 1;
}

Classic examples

1. Lower bound / upper bound

Problem idea: Given sorted array, find position to insert x. Use std::lower_bound / std::upper_bound in contests when you don't need custom logic.

2. Binary search on answer (see separate file)

When the answer is a number and checking feasibility is easier than finding it directly.

3. Minimize maximum (binary search on value)

CF 1201C — Maximum Median Binary search the median value; check if you can make at least k elements ≥ mid.

4. Count pairs with sum ≤ S (after sorting)

Sort one array, for each element binary search how many others fit.

Common pitfalls

  • Off-by-one on lo < hi vs lo <= hi.
  • Integer overflow in mid = (lo + hi) / 2 — use lo + (hi - lo) / 2.
  • Forgetting that binary search needs monotonicity.

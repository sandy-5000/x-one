Tree DFS

What it is

DFS on rooted tree to compute subtree sizes, depths, paths, and DP states in O(n).

When to use

  • Subtree queries (size, sum, max).
  • Rerooting DP prep.
  • Tree diameter (two BFS/DFS).
  • Finding parent, depth, children lists.

Template (subtree size + depth)

vector<vector<int>> adj;
vector<int> parent, depth, sz;
void dfs(int u, int p) {
    parent[u] = p;
    sz[u] = 1;
    for (int v : adj[u]) if (v != p) {
        depth[v] = depth[u] + 1;
        dfs(v, u);
        sz[u] += sz[v];
    }
}

Common tree DP pattern

long long dfs(int u, int p) {
    long long res = base(u);
    for (int v : adj[u]) if (v != p)
        res = combine(res, dfs(v, u));
    return res;
}

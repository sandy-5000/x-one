Priority Queue Tricks

What it is

priority_queue (heap) for always taking min/max element. Common in greedy scheduling and Dijkstra.

When to use

  • Process events by time/priority.
  • Merge k sorted lists.
  • Greedy: always take smallest/largest available.
  • Top-k elements (with size-limited heap).

Templates

// min-heap
priority_queue<int, vector<int>, greater<int>> pq;

// max-heap (default)
priority_queue<int> pq;

// pair by first then second
priority_queue<pair<long long,int>, vector<...>, greater<...>> pq;

Examples

1. CF 1690C — Restoring the Duration of Tasks

Sort starts, PQ for active tasks by end time.

2. CF 1203C — Common Divisors

Not PQ but multiset — multiset for dynamic min/max.

3. Huffman merge pattern

Always pop two smallest, push sum — minimize total cost.

4. CF 1705C — Mark and His Unfinished Essay

Multiset / PQ for character frequency greedy.

5. Dijkstra

PQ on (distance, node).

Multiset alternative

When you need delete arbitrary element:

multiset<int> ms;
ms.insert(x);
ms.erase(ms.find(x));  // one occurrence

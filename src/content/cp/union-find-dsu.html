Union-Find (DSU)

What it is

Disjoint Set Union maintains connected components with near O(1) union and find (path compression + union by rank).

When to use

  • Dynamic connectivity.
  • Kruskal's MST.
  • Detect cycle in undirected graph.
  • Group equivalent elements (transitive closure offline).

Template

struct DSU {
    vector<int> p, r;
    DSU(int n) : p(n), r(n, 0) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (r[a] < r[b]) swap(a, b);
        p[b] = a;
        if (r[a] == r[b]) r[a]++;
        return true;
    }
};

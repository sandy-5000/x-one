Sliding Window

What it is

A fixed or variable-size window [l, r] slides over an array, maintaining aggregate info (sum, count, max) in amortized O(n).

When to use

  • Longest/shortest subarray with sum ≤ K or ≥ K.
  • At most K distinct characters in substring.
  • Fixed window size k — max/min in each window (use deque; see monotonic-queue).

Variable window template

int l = 0, ans = 0, cur = 0;
for (int r = 0; r < n; r++) {
    cur += a[r];  // add a[r] to window
    while (cur > K) {          // shrink while invalid
        cur -= a[l];
        l++;
    }
    ans = max(ans, r - l + 1);
}

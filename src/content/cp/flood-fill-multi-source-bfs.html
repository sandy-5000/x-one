Flood Fill & Multi-Source BFS

What it is

Flood fill: DFS/BFS on grid to mark connected cells of same color. Multi-source BFS: Start BFS from all sources simultaneously — gives nearest source distance for each cell.

When to use

  • Count islands / connected components on grid.
  • Spread from multiple fire sources / nearest gate.
  • 0-1 grid movement.

Multi-source BFS template

queue<pair<int,int>> q;
vector<vector<int>> dist(n, vector<int>(m, -1));
for (auto [i,j] : sources) { dist[i][j] = 0; q.push({i,j}); }
int dx[] = {0,0,1,-1}, dy[] = {1,-1,0,0};
while (!q.empty()) {
    auto [x,y] = q.front(); q.pop();
    for (int k = 0; k < 4; k++) {
        int nx = x+dx[k], ny = y+dy[k];
        if (in_bounds && dist[nx][ny] == -1) {
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
}

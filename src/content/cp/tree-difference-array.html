Tree Difference Array

What it is

Apply range updates on tree paths or subtrees using difference technique on nodes or edges, then prefix-sum once on tree.

When to use

  • Add v to all nodes on path u–v.
  • Add v to entire subtree.
  • Many path updates, then query final values.

Subtree add template

// add val to subtree of u
diff[tin[u]] += val;
diff[tout[u] + 1] -= val;

// after all updates, DFS prefix on Euler order
void propagate(int u, int p, long long cur) {
    cur += diff[tin[u]];
    final[u] = base[u] + cur;
    for (int v : adj[u]) if (v != p) propagate(v, u, cur);
}

Path add (with LCA)

void path_add(int u, int v, long long val) {
    diff[tin[u]] += val;
    diff[tin[v]] += val;
    diff[tin[lca(u,v)]] -= val;
    diff[tin[parent[lca(u,v)]]] -= val;  // if parent exists
}

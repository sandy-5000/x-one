Bitmask DP

What it is

State includes a bitmask mask where bit i indicates whether element i is used/visited. Common for n ≤ 20 (sometimes up to 23 with pruning).

When to use

  • Traveling salesman (small n).
  • Assign people to tasks with cost matrix.
  • Count Hamiltonian paths in small graph.
  • DP over subsets: SOS DP.

Template (assignment / TSP style)

int n;
vector<vector<int>> cost(n, vector<int>(n));
const int INF = 1e9;
vector<vector<int>> dp(1 << n, vector<int>(n, INF));
dp[1][0] = 0;  // start at city 0

for (int mask = 1; mask < (1 << n); mask++)
    for (int u = 0; u < n; u++)
        if (dp[mask][u] < INF)
            for (int v = 0; v < n; v++)
                if (!(mask >> v & 1))
                    dp[mask | (1<<v)][v] = min(dp[mask|1<<v][v], dp[mask][u] + cost[u][v]);

Examples

1. TSP (n ≤ 20)

Held-Karp: O(n² · 2^n).

2. CF 580D — Kefa and Dishes

DP on subset of eaten dishes + last dish.

3. CF 1208F — Bits

Bitmask + graph connectivity.

4. SOS DP (Sum over Subsets)

for (int i = 0; i < n; i++)
    for (int mask = 0; mask < (1<<n); mask++)
        if (mask & (1<<i))
            dp[mask] += dp[mask ^ (1<<i)];

Count frequencies over all submasks.

5. Assign n jobs to n workers

dp[mask] = min cost to assign jobs in mask.

Practice

  • CF 580D — Kefa and Dishes
  • CF 1208F — Bits
  • CF 165E — Compatible Numbers (SOS DP)

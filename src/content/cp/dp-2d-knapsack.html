Dynamic Programming — 2D & Knapsack

What it is

dp[i][w] = answer using first i items with capacity/constraint w. Covers 0/1 knapsack, unbounded knapsack, and 2D grid DP.

When to use

  • Subset with weight/value limit.
  • Two sequences LCS-style.
  • Grid paths with obstacles.

0/1 Knapsack

vector<int> dp(W + 1);
for (int i = 0; i < n; i++)
    for (int w = W; w >= a[i]; w--)  // reverse for 0/1
        dp[w] = max(dp[w], dp[w - a[i]] + v[i]);

Unbounded Knapsack

for (int w = a[i]; w <= W; w++)  // forward for unbounded
    dp[w] = max(dp[w], dp[w - a[i]] + v[i]);

2D grid DP

dp[0][0] = 1;
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        if (grid[i][j] != '#')
            dp[i][j] = dp[i-1][j] + dp[i][j-1];

Examples

1. CF 189A — Cut Ribbon

Unbounded knapsack — max pieces.

2. CF 474B — Worms

Prefix sums + binary search (not DP but related counting).

3. LCS — Longest Common Subsequence

dp[i][j] = dp[i-1][j-1]+1 if match, else max(dp[i-1][j], dp[i][j-1]).

4. CF 1132F — Clear the String

Interval DP dp[l][r] — harder, upper 1900.

5. Subset sum

dp[w] boolean — can we make sum w?

Floyd-Warshall

What it is

All-pairs shortest paths for n ≤ 500 in O(n³). Also detects negative cycles and transitive closure.

When to use

  • Small dense graphs (n ≤ 400–500).
  • Count paths / reachability (modify min to sum with mod).
  • "Shortest cycle through vertex" tricks.

Template

const long long INF = 1e18;
vector<vector<long long>> dist(n, vector<long long>(n, INF));
// dist[i][i] = 0, dist[u][v] = w for edges

for (int k = 0; k < n; k++)
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (dist[i][k] < INF && dist[k][j] < INF)
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);

Examples

1. CF 295B — Greg and Graph

Reverse Floyd — add nodes one by one.

2. CF 1214F — Employment

Floyd on small graph.

3. Transitive closure (reachability)

Use dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) with OR/min on booleans.

4. Shortest cycle in graph

For each edge (u,v), answer = dist[u][v] + w(u,v) before relaxing through that edge.

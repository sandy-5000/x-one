Fenwick Tree (Binary Indexed Tree)

What it is

Supports point update and prefix sum query in O(log n). Simpler and faster than segment tree for prefix-only operations.

When to use

  • Inversions count.
  • Dynamic prefix sums.
  • Coordinate compression + frequency queries.
  • 2D Fenwick for grid (careful with constants).

Template

struct BIT {
    int n;
    vector<long long> t;
    BIT(int n) : n(n), t(n + 1) {}
    void add(int i, long long v) {
        for (++i; i <= n; i += i & -i) t[i] += v;
    }
    long long sum(int i) {  // prefix [0, i]
        long long r = 0;
        for (++i; i > 0; i -= i & -i) r += t[i];
        return r;
    }
    long long range(int l, int r) { return sum(r) - (l ? sum(l - 1) : 0); }
};

Examples

1. Inversion count

Process right to left, add(a[i], 1), query sum(a[i]-1) for smaller elements seen.

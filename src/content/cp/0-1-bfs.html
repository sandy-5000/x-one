0-1 BFS

What it is

Shortest path when edge weights are only 0 or 1. Uses deque instead of priority queue — O(V + E).

When to use

  • Graph with weights 0 and 1 only.
  • Faster than Dijkstra for this special case.
  • Grid with move cost 0 or 1.

Template

deque<int> dq;
vector<int> dist(n, INF);
dist[s] = 0;
dq.push_front(s);

while (!dq.empty()) {
    int u = dq.front(); dq.pop_front();
    for (auto [v, w] : adj[u]) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            w ? dq.push_back(v) : dq.push_front(v);
        }
    }
}

Digit DP

What it is

Count numbers in [0, N] satisfying digit constraints by DP on position with tight bound and leading zeros.

When to use

  • Count numbers with digit sum = S, no adjacent equal digits, divisible by k.
  • "How many integers ≤ N have property P?"

State

dp[pos][tight][leading_zero][...constraints]

Template sketch

string s = to_string(n);
long long dp[20][2][2][...];
memset(dp, -1, sizeof dp);

long long solve(int pos, bool tight, bool lead, ...) {
    if (pos == s.size()) return valid(...);
    if (dp[pos][tight][lead][...] != -1) return dp[...];
    long long res = 0;
    int limit = tight ? s[pos]-'0' : 9;
    for (int d = 0; d <= limit; d++) {
        bool nt = tight && (d == limit);
        bool nl = lead && (d == 0);
        res += solve(pos+1, nt, nl, update_constraints(...));
    }
    return dp[...] = res;
}

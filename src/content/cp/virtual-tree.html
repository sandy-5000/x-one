Virtual Tree

What it is

Build smallest tree containing given key nodes and their LCAs. Size O(k) for k key nodes instead of full tree.

When to use

  • Many queries on same tree with few important nodes per query.
  • DP on subset of tree nodes (key nodes from queries).
  • Combine with LCA preprocessing.

Construction

  1. Sort key nodes by Euler tour tin.
  2. Stack build tree of LCAs + key nodes.
  3. Run DP on this compressed tree.

Template sketch

vector<int> nodes;  // key nodes
sort(nodes.begin(), nodes.end(), [&](int a, int b) {
    return tin[a] < tin[b];
});
vector<int> st;
for (int u : nodes) {
    while (st.size() > 1 && !in_subtree(st.back(), u)) {
        int v = st.back(); st.pop_back();
        add_virtual_edge(st.back(), v);
    }
    st.push_back(u);
}

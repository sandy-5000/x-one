Coordinate Compression

What it is

Map large or sparse values to [0, k) by sorting unique values and replacing each with its rank. Enables array/BIT/segment tree on value domain.

When to use

  • Values up to 10⁹ but only n distinct values.
  • Need frequency array indexed by value.
  • 2D compression for sparse grid points.

Template

vector<long long> vals = a;
sort(vals.begin(), vals.end());
vals.erase(unique(vals.begin(), vals.end()), vals.end());

auto get = [&](long long x) {
    return lower_bound(vals.begin(), vals.end(), x) - vals.begin();
};

for (auto& x : a) x = get(x);
// now values in [0, vals.size())

Square Root Decomposition

What it is

Split array into blocks of size √n. Per-block aggregates give O(√n) per query/update — simple, no lazy propagation needed.

When to use

  • Range sum with point updates when segment tree feels heavy.
  • Mo's algorithm block size.
  • Frequency queries on value ranges.

Template

int B = sqrt(n) + 1;
vector<long long> block(B), a(n);

void update(int i, long long v) {
  int b = i / B;
  block[b] -= a[i]; a[i] = v; block[b] += a[i];
}

long long query(int l, int r) {
  long long res = 0;
  if (l / B == r / B) {
    for (int i = l; i <= r; i++) res += a[i];
  } else {
    for (int i = l, end = (l/B+1)*B - 1; i <= end; i++) res += a[i];
    for (int b = l/B + 1; b < r/B; b++) res += block[b];
    for (int i = r/B * B; i <= r; i++) res += a[i];
  }
  return res;
}

BFS on State Space

What it is

Model problem as graph where nodes are states (position + extra info), edges are moves. BFS gives minimum moves when all edges cost 1.

When to use

  • Minimum moves on grid with keys, switches, or parity.
  • Transform string/number to target with operations.
  • State = (row, col, mask) when mask is small.

Template

queue<State> q;
set<State> vis;
q.push(start);
vis.insert(start);
while (!q.empty()) {
    auto cur = q.front(); q.pop();
    if (cur == target) return cur.steps;
    for (auto next : transitions(cur)) {
        if (!vis.count(next)) {
            vis.insert(next);
            q.push(next);
        }
    }
}

Examples

1. CF 520B — Two Buttons

States are integers n; moves: +1 or *2.

2. CF 1063B — Labyrinth

State (x, y) — multi-source BFS variant.

3. Grid with at most one key

State (x, y, has_key) — BFS in 3D state space.

4. CF 1020B — Badge

Functional graph — detect cycle length with DFS/BFS.

5. Water jug / gcd problems

States are (a, b) amounts; pour operations.

State design tips

  • Keep state minimal — drop redundant info.
  • If state count ≤ 10⁶, BFS is usually fine.
  • Use map or hash for visited if state is not indexable.

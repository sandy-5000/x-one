MST (Kruskal & Prim)

What it is

Minimum Spanning Tree — connect all vertices with minimum total edge weight.

  • Kruskal: sort edges, DSU unite — O(E log E).
  • Prim: grow tree from source with priority queue — O(E log V).

When to use

  • Minimum cost to connect all nodes.
  • Second MST, MST + one extra edge (cycle property).
  • Kruskal reconstruction tree (advanced).

Kruskal template

sort(edges.begin(), edges.end());
DSU dsu(n);
long long cost = 0;
int used = 0;
for (auto [w, u, v] : edges) {
    if (dsu.unite(u, v)) {
        cost += w;
        if (++used == n - 1) break;
    }
}

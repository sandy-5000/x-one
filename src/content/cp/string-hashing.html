String Hashing

What it is

Polynomial rolling hash maps substring to integer for O(1) average equality check after O(n) preprocess.

When to use

  • Compare substrings quickly.
  • Find duplicate substrings.
  • Binary search on answer with substring check.

Template (double hash recommended)

using ull = unsigned long long;
const ull B1 = 31, M1 = (1ULL<<61) - 1;  // or use mod 1e9+7

struct Hasher {
    vector<ull> p, h;
    Hasher(const string& s) {
        int n = s.size();
        p.resize(n+1); h.resize(n+1);
        p[0] = 1;
        for (int i = 0; i < n; i++) {
            p[i+1] = p[i] * B1 % M1;
            h[i+1] = (h[i] * B1 + s[i]) % M1;
        }
    }
    ull get(int l, int r) {  // [l, r)
        return (h[r] - h[l] * p[r-l] % M1 + M1) % M1;
    }
};

Examples

1. CF 1200E — Compress Words

3. Longest common substring (binary search + hash)

Check all length-L hashes with set.

Compare hash of s[l..r] with hash of reversed.

5. CF 1537E — Pair of Toys

Less hashing — but string problems often combine hash + binary search.

Collision handling

  • Use two moduli or uint64_t with random base.
  • For contest problems, single mod 10^9+7 usually passes.

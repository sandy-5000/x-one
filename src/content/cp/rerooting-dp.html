Rerooting DP on Trees

What it is

First DFS computes DP for rooted tree; second DFS reroot to compute answer for every node as root in O(n).

When to use

  • "Sum of distances from each node to all others."
  • "Best value if rooted at each node."
  • Tree DP where answer depends on parent direction.

Pattern

// dfs1: compute down[u] = answer for subtree rooted at u
void dfs1(int u, int p) {
    down[u] = base(u);
    for (int v : adj[u]) if (v != p) {
        dfs1(v, u);
        down[u] = combine_down(down[u], down[v], u, v);
    }
}

// dfs2: propagate up contribution from parent
void dfs2(int u, int p, long long up) {
    ans[u] = combine(down[u], up);
    for (int v : adj[u]) if (v != p) {
        long long up_v = combine_up(up, down[u], down[v], u, v);
        dfs2(v, u, up_v);
    }
}

2-SAT

What it is

Boolean satisfiability where each clause is (a OR b). Solved by building implication graph and checking SCC — O(V + E).

When to use

  • Assign true/false with pairwise constraints.
  • "At least one of two must hold" constraints.
  • Common in Div1 B / hard Div2 D (~1900–2100).

Construction

For variable x: nodes x and ¬x. Clause (a OR b) → edges ¬a ⇒ b and ¬b ⇒ a.

Satisfiable iff no variable and its negation in same SCC.

Template sketch

// 2*n nodes: i = var i true, i^n = var i false
auto imply = [&](int u, int v) { adj[u].push_back(v); };

void either(int a, int b) {  // a OR b
    imply(a^1, b);
    imply(b^1, a);
}

// after SCC: assignment[v] = comp[v] > comp[v^1] (one valid orientation)

Convex Hull Trick & Li Chao Tree

What it is

Maintain set of linear functions y = mx + b, query minimum/maximum at point x.

  • Convex Hull Trick (CHT): deque, lines added in order of slope — O(n) or O(n log n).
  • Li Chao Tree: segment tree over x-domain — O(log X) per insert/query, works offline/online.

When to use

  • DP of form dp[i] = min(dp[j] + cost(j, i)) where cost is linear in i or j.
  • "Minimum over lines at query point x."

Li Chao template (min)

struct Line { long long m, b; long long eval(long long x) { return m*x + b; } };

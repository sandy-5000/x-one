Monotonic Stack

What it is

Stack maintaining monotonic (increasing or decreasing) sequence of indices/values. Each element pushed/popped once → O(n).

When to use

  • Next greater / smaller element (NGE, NSE).
  • Largest rectangle in histogram.
  • Stock span problems.
  • Trapping rain water.

Next Greater Element template

vector<int> nge(n, -1);
stack<int> st;  // stores indices, decreasing values
for (int i = 0; i < n; i++) {
    while (!st.empty() && a[st.top()] < a[i]) {
        nge[st.top()] = a[i];
        st.pop();
    }
    st.push(i);
}

Examples

1. Largest rectangle in histogram

For each bar, width = distance to next smaller on left and right.

2. CF 1313C2 — Skyscrapers

Monotonic stack for visibility / construction.

3. CF 5C — Longest Regular Bracket Sequence

Stack for bracket matching (related structure).

4. Sum of subarray minimums

Each element is minimum for certain ranges — use NSE/NGE.

5. CF 1693C — Keshi in Search of AmShZ

Stack + greedy on array.

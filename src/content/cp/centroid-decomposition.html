Centroid Decomposition

What it is

Recursively find tree centroid, process paths through it, remove it, repeat on remaining subtrees. Path queries in O(n log n) total.

When to use

  • Count paths with sum/condition in tree.
  • "How many pairs at distance ≤ k?"
  • Static tree path problems where HLD is awkward.

Template sketch

bool dead[MAXN];
int sz[MAXN];

int get_size(int u, int p) {
    sz[u] = 1;
    for (int v : adj[u])
        if (v != p && !dead[v]) sz[u] += get_size(v, u);
    return sz[u];
}

int get_centroid(int u, int p, int n) {
    for (int v : adj[u])
        if (v != p && !dead[v] && sz[v] > n/2)
            return get_centroid(v, u, n);
    return u;
}

void decompose(int u) {
    int n = get_size(u, -1);
    int c = get_centroid(u, -1, n);
    dead[c] = true;
    // process all paths through centroid c
    for (int v : adj[c]) if (!dead[v]) decompose(v);
}

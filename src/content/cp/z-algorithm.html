Z-Algorithm

What it is

For string s, z[i] = length of longest substring starting at i that matches prefix of s. Computed in O(n).

When to use

  • Find all occurrences of pattern (concatenate pat + # + text).
  • Period, prefix matching, string compression.
  • Alternative to KMP in many problems.

Template

vector<int> z_function(string s) {
    int n = s.size();
    vector<int> z(n);
    int l = 0, r = 0;
    for (int i = 1; i < n; i++) {
        if (i < r) z[i] = min(r - i, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    return z;
}

Examples

1. CF 535D — Tavas and Malekas

Period detection with Z.

2. Count prefix occurrences in suffix

z[i] tells match length with prefix.

3. CF 1200E — Compress Words

Compare longest common prefix/suffix via Z.

4. Pattern matching: z[pat.size()+1 + i] == pat.size() → match.

5. String period: smallest p where z[p] + p == n.

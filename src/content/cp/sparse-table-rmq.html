Sparse Table (RMQ)

What it is

Static range minimum/maximum/GCD queries in O(1) after O(n log n) preprocess. No updates.

When to use

  • Many RMQ on static array.
  • GCD on ranges (gcd is idempotent — works with sparse table).
  • LCP arrays, static RMQ in other algorithms.

Template

const int LOG = 20;
int st[MAXN][LOG], lg[MAXN];

void build(const vector<int>& a) {
    int n = a.size();
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i/2] + 1;
    for (int i = 0; i < n; i++) st[i][0] = a[i];
    for (int j = 1; (1<<j) <= n; j++)
        for (int i = 0; i + (1<<j) <= n; i++)
            st[i][j] = min(st[i][j-1], st[i+(1<<(j-1))][j-1]);
}

int query(int l, int r) {  // [l, r]
    int j = lg[r - l + 1];
    return min(st[l][j], st[r - (1<<j) + 1][j]);
}

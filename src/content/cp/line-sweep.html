Line Sweep

What it is

Sort events (points, interval endpoints) on axis and sweep a line, maintaining active set. Turns 2D geometry into 1D processing.

When to use

  • Count overlapping intervals.
  • Closest pair (sweep + balanced BST).
  • Rectangle union area.
  • Process add/remove segment events.

Template (interval overlap count)

vector<pair<int,int>> events;  // (time, +1 start / -1 end)
for (auto [l,r] : intervals) {
    events.push_back({l, +1});
    events.push_back({r+1, -1});
}
sort(events.begin(), events.end());
int active = 0, ans = 0;
for (auto [t, d] : events) {
    active += d;
    ans = max(ans, active);
}

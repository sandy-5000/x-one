Euler Tour (Tree Flattening)

What it is

DFS traversal of a tree recording entry/exit times. Turns subtree queries into array range queries on a flattened sequence.

When to use

  • Subtree sum/update on tree → segment tree on Euler tour.
  • Query path with LCA + prefix on tour.
  • Count nodes in subtree = out[u] - in[u] + 1.

Template

vector<int> tin, tout, euler;
int timer = 0;

void dfs(int u, int p) {
    tin[u] = timer;
    euler[timer++] = u;
    for (int v : adj[u]) if (v != p) dfs(v, u);
    tout[u] = timer - 1;
}

bool in_subtree(int u, int v) {  // is v in subtree of u?
    return tin[u] <= tin[v] && tout[v] <= tout[u];
}

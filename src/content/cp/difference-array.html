Difference Array

What it is

Technique for range add updates on an array in O(1) per update, then one O(n) pass to rebuild final array.

When to use

  • Many operations: add v to all elements in [l, r].
  • Offline range updates before final query.
  • Often paired with prefix sums (difference → apply updates → prefix → final array).

Template

vector<long long> diff(n + 1);
auto range_add = [&](int l, int r, long long v) {
    diff[l] += v;
    if (r + 1 < n) diff[r + 1] -= v;
};
// after all updates:
vector<long long> a(n);
long long cur = 0;
for (int i = 0; i < n; i++) {
    cur += diff[i];
    a[i] = cur;  // or a[i] += cur if building on existing
}

Examples

1. CF 295A — Greg and Array

Multiple range additions, then point queries — classic difference array.

2. Flight bookings / meeting rooms

Add +1 to [start, end] for each booking, prefix to get counts.

3. 2D difference array

Range add on submatrix — four corner updates (used less at 1950 but good to know).

4. String hashing with range add on frequency

Difference on character count array.

5. Combine with binary search on answer

Apply range updates in check function, rebuild with prefix.

Relation to prefix sums

difference(prefix(a)) = a
prefix(difference(a)) = a

Difference array is the "inverse" of prefix sum for range adds.

Mo's Algorithm (Offline Queries)

What it is

Answer offline range queries by sorting queries in block order and moving two pointers l, r with O((n + q)√n) complexity when add/remove is O(1).

When to use

  • Many range queries on static array.
  • Count distinct, frequency mode, xor sum in range.
  • Tree Mo's (Euler tour) for subtree/path queries.

Template

struct Query {
    int l, r, id;
    bool operator<(const Query& o) const {
        int b1 = l / B, b2 = o.l / B;
        if (b1 != b2) return b1 < b2;
        return (b1 & 1) ? r < o.r : r > o.r;  // hilbert-like ordering optional
    }
};

int cur_l = 0, cur_r = -1, ans = 0;

auto add = [&](int i) { /* update ans with a[i] */ };
auto remove = [&](int i) { /* undo */ };

sort(q.begin(), q.end());
for (auto [l, r, id] : q) {
    while (cur_r < r) add(++cur_r);
    while (cur_r > r) remove(cur_r--);
    while (cur_l < l) remove(cur_l++);
    while (cur_l > l) add(--cur_l);
    result[id] = ans;
}

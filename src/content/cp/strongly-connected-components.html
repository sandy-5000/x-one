Strongly Connected Components (SCC)

What it is

Partition directed graph into SCCs where every vertex reaches every other in the same component. Kosaraju or Tarjan in O(V + E).

When to use

  • Condensation DAG of SCCs.
  • 2-SAT implication graph (see two-sat.md).
  • Reachability on directed graphs.

Kosaraju template

vector<int> order, comp(n, -1);
vector<bool> vis(n);

void dfs1(int u) {
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) dfs1(v);
    order.push_back(u);
}

void dfs2(int u, int c, vector<vector<int>>& radj) {
    comp[u] = c;
    for (int v : radj[u]) if (comp[v] == -1) dfs2(v, c, radj);
}

// run dfs1 on all, reverse order, dfs2 on reversed graph

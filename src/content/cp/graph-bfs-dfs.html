Graph BFS & DFS

What it is

Traverse graph in O(V + E). BFS gives shortest path in unweighted graphs; DFS explores deeply (components, cycles, trees).

When to use

  • Connected components.
  • Shortest path (unweighted).
  • Detect cycle (directed: 3-color DFS; undirected: parent check).
  • Tree is special case of DFS.

Templates

BFS shortest path

vector<int> dist(n, -1);
queue<int> q;
dist[s] = 0; q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u])
        if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
}

DFS component

vector<bool> vis(n);
function<void(int)> dfs = [&](int u) {
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) dfs(v);
};

Catalan Numbers

What it is

C_n = (1/(n+1)) * C(2n, n) = C(2n,n) - C(2n, n+1)

Sequence: 1, 1, 2, 5, 14, 42, 132, ...

When to use

  • Valid parentheses of length 2n.
  • Binary trees with n+1 nodes.
  • Non-crossing chords on circle.
  • Paths that never go below diagonal (Dyck paths).
  • Appears in stack-sortable permutations.

Compute mod prime

long long catalan(int n) {
    return C(2*n, n) * modinv(n + 1, MOD) % MOD;
}

Examples

1. CF 5C — Longest Regular Bracket Sequence

Bracket matching — Catalan-related counting.

2. Count BSTs from sorted array

C_n distinct BSTs with n nodes.

3. Triangulation of convex (n+2)-gon

C_n ways.

4. CF 131C — The World is a Theatre

Sometimes Catalan in seating arrangements.

5. Stack permutations

Permutation is stack-sortable iff corresponds to Catalan structure.

Recognition tip

If problem asks "balanced parentheses", "never go below diagonal", or "binary tree shape" — think Catalan.

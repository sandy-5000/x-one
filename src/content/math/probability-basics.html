Probability Basics

What it is

  • P(A) = favorable / total (when outcomes equally likely).
  • Expected value: E[X] = Σ x * P(X=x).
  • Linearity: E[aX + bY] = aE[X] + bE[Y] always (even if dependent).

When to use

  • Expected number of operations.
  • Probability of winning with random choices.
  • Convert "expected value" problems to sum of indicator variables.

Indicator variable trick

// E[count of property] = sum over elements of P(element has property)

Examples

1. Expected inversions / comparisons

Sum P(pair is inverted) over all pairs.

2. CF 1191C — Tokitsukaze and Discarding Stones

Game + probability (upper range).

3. Dice / coin problems

Enumerate or use linearity.

4. Random permutation expected fixed points

E[fixed points] = n * (1/n) = 1.

5. Geometric distribution

E[trials until success] = 1/p.

Modulo probability

When answer is P/Q mod M, compute P * Q^(-1) mod M.

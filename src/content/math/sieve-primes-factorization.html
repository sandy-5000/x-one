Sieve, Primes & Factorization

What it is

  • Sieve of Eratosthenes: all primes up to n in O(n log log n).
  • Factorization: trial division up to √n, or SPF sieve for many queries.

When to use

  • Count/divide by primes.
  • Check primality for many numbers up to 10^7.
  • Mobius / divisor sieve (advanced, occasional at 1950).

Sieve template

vector<int> sieve(int n) {
    vector<bool> is_prime(n+1, true);
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i * i <= n; i++)
        if (is_prime[i])
            for (int j = i*i; j <= n; j += i)
                is_prime[j] = false;
    vector<int> primes;
    for (int i = 2; i <= n; i++) if (is_prime[i]) primes.push_back(i);
    return primes;
}

SPF (smallest prime factor) for fast factorization

vector<int> spf(n+1);
for (int i = 2; i <= n; i++) if (!spf[i]) {
    for (int j = i; j <= n; j += i) if (!spf[j]) spf[j] = i;
}
// factorize x:
while (x > 1) { int p = spf[x]; /* count p */; x /= p; }

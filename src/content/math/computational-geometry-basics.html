Computational Geometry Basics

What it is

Core tools for geometry problems at 1600–1900 — no heavy algorithms, just vectors and cross product.

Key formulas

struct P { long long x, y; };

long long dot(P a, P b) { return a.x*b.x + a.y*b.y; }
long long cross(P a, P b) { return a.x*b.y - a.y*b.x; }
long long cross(P a, P b, P c) { return cross(b-a, c-a); }

long long dist2(P a, P b) {
    return (a.x-b.x)*(a.x-b.x) + (a.y-b.y)*(a.y-b.y);
}

// orientation: >0 left turn, <0 right, =0 collinear
int orient(P a, P b, P c) {
    long long v = cross(a, b, c);
    return (v > 0) - (v < 0);
}

Polygon area (shoelace)

long long area2(vector<P>& p) {
    long long s = 0;
    int n = p.size();
    for (int i = 0; i < n; i++)
        s += cross(p[i], p[(i+1)%n]);
    return abs(s);  // divide by 2 for area
}

When to use

  • Collinear check, point in polygon.
  • Convex polygon problems.
  • Line intersection, CCW ordering.

Bijection & Counting Proofs

What it is

Prove two sets have the same size by giving a one-to-one correspondence (bijection). Common in combinatorics problems instead of brute formula.

When to use

  • "Show count equals Fibonacci / Catalan / C(n,k)."
  • Map paths to binary strings, trees to sequences.
  • Prove recurrence by constructing bijection.

Classic bijections

ProblemBijection to
Dyck paths (never below diagonal)Catalan
Valid parentheses of length 2nCatalan
Binary trees with n nodesCatalan
Monotone grid paths n×mC(n+m, n)
Permutation ↔ inversion table (limited)counting

Technique in contests

  1. Small cases — spot OEIS / known sequence.
  2. Try to map each object to a unique structure you can count.
  3. Often reveals DP recurrence.

Examples

1. CF 131C — The World is a Theatre

Combinatorial bijection.

2. CF 5C — Longest Regular Bracket Sequence

Brackets ↔ Catalan structure.

3. CF 149D — Coloring Brackets

Bracket matching bijection.

4. Paths with steps R,U ↔ binary strings with n zeros and m ones.

5. CF 118D — Caesar's Legions

Soldier arrangements ↔ combinatorial objects.

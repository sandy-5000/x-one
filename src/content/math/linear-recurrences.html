Linear Recurrences

What it is

Sequence defined by:

f(n) = c1*f(n-1) + c2*f(n-2) + ... + ck*f(n-k)

Fibonacci: F(n) = F(n-1) + F(n-2).

Solve for huge n using matrix exponentiation or characteristic equation (when only value needed).

Matrix method (general)

State vector [f(n), f(n-1), ..., f(n-k+1)] × transition matrix^k.

// Fibonacci: [[1,1],[1,0]]^n

Binet's formula (Fibonacci, theoretical)

F(n) = (φ^n - ψ^n) / √5   where φ = (1+√5)/2

Rarely used in contests (precision issues) — prefer matrix exp.

When to use

  • CF problems with n up to 10^18 in recurrence.
  • Count ways that follow Fibonacci-like growth.
  • DP with linear transition.

Examples

Linear recurrence mod.

2. CF 118D — Caesar's Legions

Sometimes recurrence in combinatorics.

3. Tiling 2×n board with 1×2 dominoes → Fibonacci.

4. CF 1110C — Triangles

Recurrence in geometry count.

5. Tribonacci, Padovan — same matrix technique, larger matrix.

GCD, LCM & Extended Euclidean

What it is

  • GCD(a,b): greatest common divisor — __gcd(a,b) in C++17.
  • LCM(a,b) = a / gcd(a,b) * b (divide first to avoid overflow).
  • Extended Euclidean: find x, y such that a*x + b*y = gcd(a,b).

When to use

  • Simplify fractions.
  • Check if linear Diophantine ax + by = c has solution.
  • Modular inverse when mod is not prime.
  • Group numbers by GCD (CF 1203C).

Extended GCD template

long long extgcd(long long a, long long b, long long &x, long long &y) {
    if (!b) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = extgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

Examples

1. CF 1203C — Common Divisors

Sort + GCD of entire array interactions.

2. CF 1512G — Shortest Path with Obstacle

GCD of step sizes on number line.

3. Linear congruence ax ≡ b (mod m)

Solve using extgcd; solution exists iff gcd(a,m) | b.

4. LCM of array

lcm = a[0]; for (x : a) lcm = lcm / gcd(lcm,x) * x;

5. Coprime check

gcd(a,b) == 1.

Euclidean algorithm complexity

O(log min(a,b)) — very fast even for 10^18.

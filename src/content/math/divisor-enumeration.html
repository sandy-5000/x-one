Divisor Enumeration — O(√n)

What it is

List all divisors of n by iterating i from 1 to √n. If i | n, both i and n/i are divisors.

Template

vector<long long> get_divisors(long long n) {
    vector<long long> d;
    for (long long i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            d.push_back(i);
            if (i != n / i) d.push_back(n / i);
        }
    }
    sort(d.begin(), d.end());
    return d;
}

Enumerate divisors of all numbers 1..n

vector<vector<int>> divs(n+1);
for (int i = 1; i <= n; i++)
    for (int j = i; j <= n; j += i)
        divs[j].push_back(i);

When to use

  • Factor n by trial division up to √n.
  • GCD problems — iterate divisors of GCD.
  • Count coprime pairs using divisor structure.

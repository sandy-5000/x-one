Lucas Theorem & nCr mod prime

What it is

Compute C(n, r) mod p when n, r are huge (up to 10^18) but p is small prime, using Lucas theorem digit-by-digit in base p.

When to use

  • nCr mod prime where n > MOD and MOD is prime (~10^3 to 10^6).
  • Digit DP + combinatorics.
  • When factorial precompute limit is exceeded.

Lucas theorem

C(n, r) mod p = Π C(n_i, r_i) mod p

where n_i, r_i are digits of n, r in base p.

Template

long long C_small(long long n, long long r, long long p) {
    if (r < 0 || r > n) return 0;
    if (r == 0 || r == n) return 1;
    return fac[n] * invfac[r] % p * invfac[n-r] % p;
}

long long lucas(long long n, long long r, long long p) {
    if (r == 0) return 1;
    return C_small(n % p, r % p, p) * lucas(n / p, r / p, p) % p;
}

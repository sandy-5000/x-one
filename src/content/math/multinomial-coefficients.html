Multinomial Coefficients

What it is

Number of ways to arrange n items where there are c1 of type 1, c2 of type 2, ...:

n! / (c1! * c2! * ... * ck!)   where c1+c2+...+ck = n

Also: ways to put n distinct balls into labeled boxes of fixed sizes.

When to use

  • Anagram counting with repeated letters.
  • Permutations with duplicates.
  • Multinomial theorem expansions.

Template

long long multinomial(int n, vector<int>& c) {
    long long res = fac[n];
    for (int x : c) res = res * invfac[x] % MOD;
    return res;
}

Relation to stars and bars

  • Multiset permutations: multinomial.
  • Identical items into bins: stars and bars (combinations).

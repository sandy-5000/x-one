Sum Formulas & Series

What it is

Closed-form sums used constantly to avoid O(n) loops when n is huge.

Essential formulas

SumFormula
1 + 2 + ... + nn(n+1)/2
1² + 2² + ... + n²n(n+1)(2n+1)/6
1³ + ... + n³(n(n+1)/2)²
Geometrica + ar + ... + ar^(n-1) = a(1-r^n)/(1-r)
Arithmetic seriesfirst + last) * count / 2

When to use

  • Count operations in nested loops (turn O(1) formula).
  • CF problems asking sum of f(i) over range.
  • Pair counting: total pairs = n(n-1)/2.

Examples

1. CF 1208C — Magic Grid

Grid sums with arithmetic series.

2. Count pairs (i, j) with i < j

n*(n-1)/2 — use __int128 if n up to 10^9.

3. Sum of floor(n/i) for all i

O(√n) trick — group equal quotients (occasional Div2 D).

4. CF 1338A — Powered Addition

Min operations related to gaps — sum of differences.

5. Harmonic-like sums

Σ n/i for i=1..n appears in some greedy analyses.

Safe computation

long long pairs(long long n) {
    return (__int128)n * (n - 1) / 2;
}

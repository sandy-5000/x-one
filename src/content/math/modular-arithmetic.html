Modular Arithmetic

What it is

Compute (a + b) % m, (a * b) % m, (a - b) % m without overflow. Foundation for almost all counting problems on CF.

When to use

  • Answer required mod 10^9 + 7 or 998244353.
  • Prevent integer overflow in products.
  • Cyclic patterns (days, rotations).

Rules

(a + b) % m = ((a % m) + (b % m)) % m
(a * b) % m = ((a % m) * (b % m)) % m
(a - b) % m = ((a % m) - (b % m) + m) % m   // add m before final %

Safe multiply (avoid overflow)

long long mul(long long a, long long b, long long m) {
    return (long long)((__int128)a * b % m);
}

Examples

Less mod — but many Div2 C need mod on answer.

3. CF 118D — Caesar's Legions

4. Negative numbers mod

((a % m) + m) % m always gives [0, m).

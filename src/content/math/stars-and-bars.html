Stars and Bars

What it is

Count ways to distribute n identical items into k distinct bins (bins may be empty):

C(n + k - 1, k - 1) = C(n + k - 1, n)

Non-negative integer solutions to x1 + x2 + ... + xk = n.

Variants

ConstraintFormula
Each xi ≥ 0C(n+k-1, k-1)
Each xi ≥ 1 (non-empty bins)C(n-1, k-1)
Each xi ≥ aisubstitute yi = xi - ai
Upper boundsinclusion-exclusion

When to use

  • Distribute candies, votes, identical balls into boxes.
  • Count solutions to linear Diophantine with non-negativity.
  • DP alternative when formula applies directly.

Examples

1. CF 118D — Caesar's Legions

Soldiers into groups — combinatorics distribution.

2. Ways to split sum n into k parts

Stars and bars with order (compositions): C(n-1, k-1) for positive parts.

3. CF 455A — Boredom variant

Count arrays with fixed sum.

4. Number of monotonic paths with extra constraints.

5. x1 + x2 + ... + xk ≤ n → C(n+k, k) (add slack variable).

Template

// n identical into k distinct bins, bins may be empty
long long ways = C(n + k - 1, k - 1, MOD);

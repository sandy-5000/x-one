Burnside's Lemma (Symmetry Counting)

What it is

Count distinct objects under symmetry group G:

|Orbits| = (1/|G|) * Σ fix(g)   over g ∈ G

fix(g) = number of configurations unchanged by symmetry g.

When to use

  • Count necklaces / bracelets (cyclic rotation).
  • Colorings up to rotation/reflection.
  • Polya enumeration lite at ~1900.

Necklace example (n beads, k colors)

Rotation by shift fixes a coloring iff all beads in cycles have same color.

long long fix(int shift, int n, int k) {
    int g = gcd(shift, n);
    return power(k, g, MOD);  // g cycles, each independent
}

long long necklaces(int n, int k, long long mod) {
    long long sum = 0;
    for (int shift = 0; shift < n; shift++)
        sum = (sum + fix(shift, n, k)) % mod;
    return sum * modinv(n, mod) % mod;
}

Legendre's Formula

What it is

Exponent of prime p in n!:

e_p(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ...

When to use

  • Trailing zeros in n! (base 10): min over 2,5 but usually ⌊n/5⌋ + ⌊n/25⌋ + ....
  • Largest k where p^k | n!.
  • Count factors of prime in binomial coefficients.

Trailing zeros template

int trailing_zeros(int n) {
    int cnt = 0;
    for (long long p = 5; p <= n; p *= 5)
        cnt += n / p;
    return cnt;
}

Prime exponent in n!

int legendre(int n, int p) {
    int e = 0;
    for (long long pk = p; pk <= n; pk *= p)
        e += n / pk;
    return e;
}

Derangements

What it is

A derangement is a permutation with no fixed point (no i where p[i] = i).

!n = n! * Σ (-1)^k / k!   for k = 0..n
     = (n-1) * (!(n-1) + !(n-2))   recurrence

First values: !0=1, !1=0, !2=1, !3=2, !4=9, !5=44.

When to use

  • Permutations with "nobody stays in own seat" constraints.
  • Inclusion-exclusion on fixed points.
  • Probability that random permutation has no fixed point ≈ 1/e.

Precompute mod M

vector<long long> der(n+1);
der[0] = 1; der[1] = 0;
for (int i = 2; i <= n; i++)
    der[i] = (i - 1) * (der[i-1] + der[i-2]) % MOD;

Inclusion-exclusion formula

Count permutations with exactly k fixed points:

C(n,k) * !(n-k)

Examples

1. CF 888D — Almost Identity Permutations

Count perms with exactly n-k fixed points.

2. Hat-check problem

Probability all wrong = !n / n!.

3. CF 1228C — Trees

Sometimes derangement-style counting.

4. Secret Santa / derangement count mod prime.

5. At most k fixed points — sum over i=0..k of C(n,i)*!(n-i).

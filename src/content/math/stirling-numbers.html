Stirling Numbers (2nd Kind)

What it is

S(n,k) = ways to partition n distinct objects into k non-empty unordered subsets.

Recurrence:

S(n,k) = k * S(n-1,k) + S(n-1,k-1)
S(n,1) = S(n,n) = 1

Bell number: B(n) = Σ S(n,k) for k=1..n = total partitions.

When to use

  • Partition set into groups (upper 1900 math).
  • Count surjective functions: k! * S(n,k).
  • DP with "assign to k identical bins, each non-empty."

Precompute

vector<vector<long long>> S(n+1, vector<long long>(n+1));
S[0][0] = 1;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i; j++)
        S[i][j] = (j * S[i-1][j] + S[i-1][j-1]) % MOD;

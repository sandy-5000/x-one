Inclusion-Exclusion Principle

What it is

Count union of sets by alternating sums over intersections:

|A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

When to use

  • Count numbers in [1,N] divisible by at least one of given primes.
  • Count permutations with no fixed points (derangements).
  • 2–3 constraints — enumerate bitmask of which constraints violated.

Two-set template

// count x in [1, n] divisible by a or b
long long cntA = n / a, cntB = n / b;
long long cntAB = n / lcm(a, b);
long long ans = cntA + cntB - cntAB;

k constraints bitmask

long long ans = 0;
for (int mask = 1; mask < (1<<k); mask++) {
    long long lcm_val = 1;
    int bits = 0;
    for (int i = 0; i < k; i++) if (mask>>i & 1) {
        bits++;
        lcm_val = lcm(lcm_val, a[i]);
        if (lcm_val > n) break;
    }
    if (lcm_val > n) continue;
    long long add = n / lcm_val;
    if (bits % 2) ans += add;
    else ans -= add;
}

Examples

1. Count coprime to all small primes in range

Inclusion-exclusion on divisibility.

2. CF 1037C — Equal Elements

Sometimes IE on prime factor conditions.

3. Derangements

!n = n! * Σ (-1)^k / k! for k=0..n.

4. GCD = 1 counting

count(gcd=1) = Σ μ(d) * floor(n/d) — Mobius form of IE.

5. At most 3 dimensions — brute IE works

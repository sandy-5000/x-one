Expected Value — Linearity

What it is

Linearity of expectation (always true, even if variables are dependent):

E[X + Y] = E[X] + E[Y]
E[cX] = c * E[X]

Most CF probability problems reduce to summing probabilities of indicator variables.

Indicator variable trick

// E[number of pairs with property] = Σ P(pair (i,j) has property)
for each pair (i,j)
    ans += probability_or_0_1_indicator;

When to use

  • "Expected number of ..." in random process.
  • Average value over all permutations / random choices.
  • Avoid complex joint distributions — use linearity.

Examples

1. Expected fixed points in random permutation

E[count] = Σ P(i is fixed) = n * (1/n) = 1.

2. CF 1191C — Tokitsukaze and Discarding Stones

Game + expected moves.

3. Expected inversions in random array

E = n(n-1)/4 — each pair 50% inverted.

4. CF 1107F — Vasya and Endless Credits

Expected value DP.

5. Random walk expected steps — markov + linearity on states.

Modulo form

When answer is P/Q mod M: compute P * inv(Q) mod M.

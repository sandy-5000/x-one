Modular Inverse (Fermat)

What it is

a^(-1) mod p is the number x such that a*x ≡ 1 (mod p). When p is prime and gcd(a,p)=1:

a^(-1) ≡ a^(p-2) (mod p)   // Fermat's little theorem

When to use

  • Division mod prime: (a / b) % p = a * inv(b) % p.
  • Precompute invfac for nCr.
  • Probability mod p.

Template

long long modinv(long long a, long long p) {
    return power(a, p - 2, p);
}

For composite mod, use extended Euclidean (see gcd-lcm-extended-euclid.md).

Precompute all inverses 1..n mod p

vector<long long> inv(n+1);
inv[1] = 1;
for (int i = 2; i <= n; i++)
    inv[i] = (p - p/i) * inv[p % i] % p;

Examples

1. nCr mod prime

C(n,r) = fac[n] * invfac[r] % p * invfac[n-r] % p.

2. CF 118D — Caesar's Legions

Combinatorics needs inverse factorials.

3. Expected value problems mod p

Divide by count using inverse.

4. Linear recurrence divide

Normalize DP transitions with modular division.

5. Wilson's theorem (rare)

(p-1)! ≡ -1 (mod p) for prime p — occasional trick.

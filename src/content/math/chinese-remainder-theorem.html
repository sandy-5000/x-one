Chinese Remainder Theorem (CRT)

What it is

Given remainders r_i modulo pairwise coprime moduli m_i, there is a unique solution mod M = Π m_i.

When to use

  • Reconstruct number from residues mod several coprime primes.
  • Combine congruences after factorizing modulus.
  • Occasional math Div2 D at ~1800-1900.

Two-modulus template

// solve x ≡ a1 (mod m1), x ≡ a2 (mod m2), gcd(m1,m2)=1
long long m1, m2, a1, a2;
long long y1, y2;
extgcd(m1, m2, y1, y2);
long long M = m1 * m2;
long long x = (a1 * m2 * y2 + a2 * m1 * y1) % M;
if (x < 0) x += M;

General CRT (coprime moduli)

long long crt(const vector<long long>& r, const vector<long long>& m) {
    long long x = 0, M = 1;
    for (int i = 0; i < r.size(); i++) {
        long long a = r[i], mod = m[i];
        long long p = M, inv, y;
        extgcd(p, mod, inv, y);
        long long t = ((a - x) % mod + mod) % mod * inv % mod;
        x += t * p;
        M *= mod;
        x %= M;
    }
    return (x + M) % M;
}

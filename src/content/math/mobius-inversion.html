Möbius Inversion

What it is

Number-theoretic inclusion-exclusion on divisors:

g(n) = Σ f(d)  over d|n   ⟺   f(n) = Σ μ(d) * g(n/d)  over d|n

μ(n) = Möbius function: 0 if squared prime factor, (-1)^k if k distinct primes.

When to use

  • Count coprime pairs in range.
  • GCD = 1 counting.
  • Divisor-sum inversion problems.

Precompute μ with sieve

vector<int> mu(n+1), primes;
vector<bool> is_comp(n+1);
mu[1] = 1;
for (int i = 2; i <= n; i++) {
    if (!is_comp[i]) { primes.push_back(i); mu[i] = -1; }
    for (int p : primes) {
        if (i * p > n) break;
        is_comp[i*p] = true;
        if (i % p == 0) { mu[i*p] = 0; break; }
        mu[i*p] = -mu[i];
    }
}

Count coprime pairs (classic)

ans = Σ μ(d) * C(count of multiples of d, 2)

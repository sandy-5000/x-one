Floor Sum Trick — Σ⌊n/i⌋

What it is

Compute Σ_{i=1}^{n} ⌊n/i⌋ in O(√n) by grouping equal quotients.

For fixed q = ⌊n/i⌋, all i in (⌊n/(q+1)⌋, ⌊n/q⌋] give the same floor value.

When to use

  • Sum of divisors-style loops too slow for n up to 10^12.
  • Count lattice points under hyperbola xy ≤ n.
  • Number theory counting problems.

Template

long long floor_sum(long long n) {
    long long ans = 0;
    for (long long l = 1, q; l <= n; l = q + 1) {
        q = n / l;
        long long r = n / q;
        ans += q * (r - l + 1);
    }
    return ans;
}

General form

Σ_{i=1}^{n} ⌊(a*i + b) / m⌋

Use extended floor sum algorithm (AtCoder Library) for contests — O(log m).

Divisor Functions (τ and σ)

What it is

  • τ(n) = number of divisors of n.
  • σ(n) = sum of divisors of n.

Computed for all 1..n via sieve in O(n log n).

Sieve template

vector<int> tau(n+1), sigma(n+1);
for (int i = 1; i <= n; i++) {
    for (int j = i; j <= n; j += i) {
        tau[j]++;
        sigma[j] += i;
    }
}

Single n factorization

If n = p1^a1 * p2^a2 * ...:

τ(n) = (a1+1)(a2+1)...
σ(n) = (p1^(a1+1)-1)/(p1-1) * ...

When to use

  • "How many divisors does n have?"
  • Sum of divisors queries.
  • Multiplicative functions on factorization.

Examples

Divisors and GCD structure.

2. CF 1037C — Equal Elements

Prime power / divisor logic.

Exactly 2 divisors → product of 2 primes.

4. Highly composite / divisor counting in range.

5. σ(n) = n → perfect numbers (rare in contests).

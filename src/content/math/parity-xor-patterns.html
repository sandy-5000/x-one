Parity, XOR & Modular Patterns

What it is

Exploit parity (even/odd), XOR properties, and cyclic modular patterns to simplify problems.

Key facts

PropertyRule
XOR inversea ^ a = 0, a ^ 0 = a
XOR commutativeorder doesn't matter
Parity of sum(a+b) % 2 = (a%2 + b%2) % 2
(-1)^k patternalternating sums
mod 2 arithmeticXOR equals addition mod 2 per bit

Prefix XOR trick

Subarray xor [l,r] = pref[r+1] ^ pref[l].

When to use

  • "Can we make all elements zero with xor operations?"
  • Graph bipartite ↔ no odd cycle (parity BFS).
  • Nim XOR = 0 losing position.

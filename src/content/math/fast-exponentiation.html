Fast Exponentiation

What it is

Compute a^b mod m in O(log b) using binary exponentiation.

When to use

  • Modular inverse via Fermat.
  • Matrix exponentiation for linear recurrences.
  • Count huge powers with mod.

Template

long long power(long long a, long long b, long long m) {
    long long res = 1 % m;
    a %= m;
    while (b > 0) {
        if (b & 1) res = (__int128)res * a % m;
        a = (__int128)a * a % m;
        b >>= 1;
    }
    return res;
}

5. Modular inverse

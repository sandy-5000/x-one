Modular Inverse (Composite Modulus)

What it is

a^(-1) mod m exists iff gcd(a, m) = 1. Use extended Euclidean (not Fermat) when m is not prime.

long long inv(long long a, long long m) {
    long long x, y;
    long long g = extgcd(a, m, x, y);
    if (g != 1) return -1;  // no inverse
    return (x % m + m) % m;
}

When to use

  • Modulus is composite (e.g. 10^9+6 is not prime... actually 10^9+6 is not prime; 10^9+7 is prime).
  • CRT splits problem into prime powers.
  • Division in modular arithmetic.

CRT + inverse pattern

Solve mod m = p1^a1 * p2^a2 ... by solving mod each prime power, then CRT combine.

Examples

1. Division mod 10^9+6

Use inverse via extgcd or Fermat if you verify modulus is prime.

2. CF 1225D — Unusual Product

Modular division in counting.

3. Probability P/Q mod M — P * inv(Q) mod M.

4. Linear congruence ax ≡ b (mod m) — solve with extgcd.

5. CRT reconstruction after computing inverses mod each factor.

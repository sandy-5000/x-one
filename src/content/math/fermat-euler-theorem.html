Fermat's & Euler's Theorems

What it is

Fermat (p prime): a^(p-1) ≡ 1 (mod p) when gcd(a,p)=1. So a^(-1) ≡ a^(p-2) (mod p).

Euler: a^φ(n) ≡ 1 (mod n) when gcd(a,n)=1. So a^k mod n has period dividing φ(n).

When to use

  • Reduce huge exponent: a^b mod m → a^(b mod φ(m)) when gcd holds.
  • Cycle length in modular exponentiation.
  • Modular inverse when modulus is prime.

Template (power mod m, b huge)

long long power_mod(long long a, long long b, long long m) {
    if (m == 1) return 0;
    long long ph = phi(m);  // precompute
    if (b >= ph) b = ph + b % ph;  // careful when gcd(a,m)!=1
    return power(a, b, m);
}

Caution: When gcd(a, m) ≠ 1, Euler reduction needs care — factor m or use direct pow.

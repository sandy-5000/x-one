0-1 BFS

What it is

Shortest path when edge weights are only 0 or 1. Uses deque instead of priority queue — O(V + E).

When to use

  • Graph with weights 0 and 1 only.
  • Faster than Dijkstra for this special case.
  • Grid with move cost 0 or 1.

Template

deque<int> dq;
vector<int> dist(n, INF);
dist[s] = 0;
dq.push_front(s);

while (!dq.empty()) {
    int u = dq.front(); dq.pop_front();
    for (auto [v, w] : adj[u]) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            w ? dq.push_back(v) : dq.push_front(v);
        }
    }
}

Examples

1. CF 173B — Chamber of Secrets

0-1 graph shortest path.

2. CF 1301D — Time to Run

Grid BFS with 0/1 costs.

3. CF 1076D — Edge Deletion

Transform to 0-1 BFS.

4. Minimum swaps to sort (implicit 0-1).

5. CF 1915G — Gellyfish and Flaming Peony

Sometimes 0-1 or small weight BFS.

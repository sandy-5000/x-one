Sprague-Grundy (Game Theory)

What it is

Impartial games: each position has Grundy number (nimber) = mex of Grundy numbers of reachable positions. Position is losing iff Grundy = 0.

When to use

  • Nim, take-away games on piles.
  • XOR of pile Grundy numbers = 0 → losing for first player.
  • Combine independent subgames.

Template

vector<int> grundy(MAXN, -1);

int mex(const unordered_set<int>& s) {
    int m = 0;
    while (s.count(m)) m++;
    return m;
}

int calc(int state) {
    if (grundy[state] != -1) return grundy[state];
    unordered_set<int> reachable;
    for (int next : moves(state)) reachable.insert(calc(next));
    return grundy[state] = mex(reachable);
}

Nim rule

n piles with sizes a[i] → Grundy = a[1] ^ a[2] ^ ... ^ a[n]. First player wins iff XOR ≠ 0.

Examples

2. CF 1375C — Element Extermination

3. CF 1107F — Vasya and Endless Credits

Sprague-Grundy on states.

4. Take 1, 2, or k stones from pile.

5. Graph game: move token, last move wins — compute Grundy per node.

Euler's Totient φ(n)

What it is

φ(n) = count of integers in [1, n] coprime to n.

If n = p1^a1 * p2^a2 * ...:

φ(n) = n * Π (1 - 1/pi)   over distinct primes pi dividing n

When to use

  • Count coprime pairs.
  • Euler's theorem: a^φ(n) ≡ 1 (mod n) when gcd(a,n)=1.
  • Cycle length in modular exponentiation.

Compute φ(n) for single n

long long phi(long long n) {
    long long result = n;
    for (long long p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            while (n % p == 0) n /= p;
            result -= result / p;
        }
    }
    if (n > 1) result -= result / n;
    return result;
}

Sieve totient for all 1..n

vector<int> phi(n+1);
iota(phi.begin(), phi.end(), 0);
phi[1] = 1;
for (int i = 2; i <= n; i++) if (!phi[i]) {
    for (int j = i; j <= n; j += i) {
        if (!phi[j]) phi[j] = j;
        phi[j] -= phi[j] / i;
    }
}

Examples

1. Count a^b mod m cycles

Period divides φ(m) when gcd(a,m)=1.

2. CF 1225D — Unusual Product

Coprime / factorization related.

3. Inclusion-exclusion count coprime

Σ μ(d) * (n/d) — alternative to φ on intervals.

4. RSA-style problems (rare in CF)

φ(pq) = (p-1)(q-1).

5. Order of element mod p

Smallest k with a^k ≡ 1 divides φ(p)=p-1.
